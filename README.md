# Pedagogy Tools

Open educational tools for clinical herbalism pedagogy.

Built with [Claude](https://claude.ai). Hosted on [GitHub Pages](https://johncourie.github.io/pedagogy-tools). No external dependencies beyond Google Fonts.

## Tools

- **When an Herb Gets Labeled Dangerous** — An interactive framework for interrogating herb safety claims, covering causality methods, bias taxonomy, and parallel case studies in green tea and kratom. → [Open](https://johncourie.github.io/pedagogy-tools/safety/herb-safety-claims/)
- **Whose Voice Is It?** — Sort Traditional Ecological Knowledge, ethnobotany, and the peer-reviewed sources that only look like them. → [Open](https://johncourie.github.io/pedagogy-tools/research/whose-voice/)
- **Pathfinding the Historical Texts** — Read pre-Flexner American herbal medicine with the conventions it leaves unsaid: why the texts matter, who wrote what, a toolkit for ratios, units and archaic terms, and practice decoding entries. → [Open](https://johncourie.github.io/pedagogy-tools/research/historical-texts/)
- **Link Self-Defense** — Read what a link carries, strip the tracking, cite it correctly in APA 7, and share it without leaking information about yourself. Runs entirely in the browser. → [Open](https://johncourie.github.io/pedagogy-tools/research/link-self-defense/)
- **Who Keeps the Score** — Chronic pain after a crushed wrist, for herbal practitioners: pain narratives, the receptors herbal claims target, posology, and a case triage. → [Open](https://johncourie.github.io/pedagogy-tools/reference/who-keeps-the-score/)

## Development

All tools are static HTML/CSS/JS — no build step required. Serve locally with any static file server:

```bash
npx serve .
```
